# Makepad Documentation

## Overview
Welcome to the official documentation for Makepad, a Rust-based framework for building cross-platform applications with a focus on performance and ease of use. This documentation covers everything from getting started to advanced topics, with practical examples and best practices.

- [Building User Interfaces](guides/building_ui.md) - Creating interactive UI components and handling user input

## How to Use This Documentation

### For Beginners
If you're new to Makepad, start with the [Getting Started Guide](guides/getting_started.md) and work through the tutorials in order. These guides will introduce you to the core concepts and help you build your first applications.

### For Experienced Developers
If you're already familiar with Makepad or Rust, you might want to jump directly to the specific topics you're interested in. The [API Reference](api/) section provides detailed documentation for all public functions and types.

### For Contributors
If you're interested in contributing to Makepad, check out the [Examples and Best Practices](examples/) section for guidance on writing efficient, maintainable code.
